# Лабораторная работа 3. Кластеризация

Ненашкин В. Д., группа АВТ-313, НГТУ.

В [lab3.ipynb](lab3.ipynb) группируем образцы вин по химическому составу и сравниваем K-means с методом Уорда. В дополнительной части автоэнкодировщик сжимает признаки, а DEC уточняет разбиение в скрытом пространстве. Метки сортов используются для внешней оценки после подбора настроек.

## Данные

`wine.csv` содержит 178 образцов и 13 признаков набора Wine. В CSV добавлены названия столбцов, значения совпадают с исходным файлом. Авторы набора S. Aeberhard и M. Forina. [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/109/wine), [лицензия CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

SHA-256: `cea9a880b6c07ebcbe92aa34f723c13e55935ee225e7ce80cbd973c2ecd89031`.

## Запуск

В папке репозитория с Python 3.13:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter notebook lab3.ipynb
```

Выберите ядро окружения и выполните ячейки по порядку. Графики и таблицы доступны в сохранённых выводах. При запуске ноутбук также записывает результаты в `runtime/`.
